| Backup validation | Only a restore proves a backup | Logs/size/notifications |
| Database types | Relational / NoSQL (KV, doc, column, graph) | Matching type to use case |
| Replication | Synchronous vs asynchronous | Latency vs consistency trade-off |
| BASE vs ACID | Eventual consistency model | — |
