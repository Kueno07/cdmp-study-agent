# Reference & Master Data — Ch.10 (10%)
| Concept | Testable angle | Common confusions |
|---|---|---|
| Master vs Reference data | Key business entities vs controlled value sets | Reference = code lists; Master = Customer/Product |
| Golden Record | Reconciled best-version via survivorship | "Most recent" or "highest SLA system" |
| Survivorship rules | Attribute-level source-of-truth selection | Retention or dedup |
| System of Record vs Reference | Authoritative source vs consuming system | MDM hub is always SOR |
| MDM styles | Registry / Consolidation / Coexistence / Transaction | Registry = index only; Transaction = hub is SOR |
| Party data | Generic person/org in multiple roles | Only employees or customers |
| Match/merge | Deterministic vs probabilistic | Survivorship |
