# Data Warehousing & BI — Ch.11 (10%)
| Concept | Testable angle | Common confusions |
|---|---|---|
| CDC | Captures only changed records | Full extract or schema-change detection |
| ETL vs ELT | Transform-before vs transform-in-target | ELT suits cloud DW with elastic compute |
| ODS vs DW | Current operational vs historical analytical | Reversing volatility/history |
| Inmon vs Kimball | Top-down 3NF EDW vs bottom-up conformed marts | Reversing the two |
| Conformed dimension | Shared identical dim enabling drill-across | Replicated dimension |
| Release management | Backward-compatible additive deployment | Big-bang annual release |
| Fact table types | Transaction / periodic snapshot / accumulating | Snapshot additivity rules |
| Data mart | Subject/departmental subset | Dependent vs independent marts |
